# Project Assets

This directory contains visual assets and screenshots for the Weather App repository.

## Directory Structure

```
assets/
├── screenshots/
│   └── weather-app-preview.png   # Recommended preview image for repository README
└── README.md
```

## Screenshot Guidelines

To add or update the application preview screenshot displayed in the main `README.md`:

1. Run the application locally (`python backend/app.py`).
2. Search for any representative city (e.g. "Tokyo", "London", or "San Francisco").
3. Capture a high-resolution screenshot of the browser window.
4. Save the image as `weather-app-preview.png` inside `assets/screenshots/`.
5. The main [README.md](../README.md) preview link will automatically render your screenshot.
